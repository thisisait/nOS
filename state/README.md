# state/

Committed, declared facts about the estate, grouped by realm. Words are the
lexicon's (`state/genome/lexicon.yml`, rendered to `docs/glossary.md`).

Runtime state is **not** here. It lives in `~/.nos/` (the runtime home):
`state.yml` (written by `roles/pazny.state_manager/`), `smoke-catalog.runtime.yml`
(written by `roles/pazny.apps_runner/`), secrets, events. A converge never writes
into this directory (gate: `tests/anatomy/test_a_converge_writes_nothing_into_the_checkout.py`).

## By realm

| realm | path | holds |
|---|---|---|
| genome | `genome/` | what exists: the lexicon, genes, entity and tissue schemas |
| organ | `manifest.yml` | one row per organ (service or host daemon); Traefik routes from it |
| tissue | `tissues/` | tissue manifests |
| memory | `keap-tables/` | KEAP DataTable definitions (seeding them is opt-in) |
| habitat | `habitat/` | what lives beside the organism: `router.yml` (the WAN router), `llm-backends.yml` (the LLM backends cells may call) |
| law companions | see below | law kept as data, read by the code that enforces it |
| fixtures | `fixtures/` | test and bench data: seeds, ISDOC samples, `fable/`, `ops-task-families/`, `ops-harness/`, `vision-bench/`, `pipeline-exercise/`, `local-model-bench.yml` |
| schema | `schema/` | JSON Schemas for state, manifest, migrations, upgrades, events, agents |
| generated | see below | written by a tool, never by hand |

Law companions (listed in `ssot/INDEX.yml` `realms.doctrine.companions`):
`judge-sets.yml`, `gdpr-consent-map.yml`, `gdpr-erasure-map.yml`,
`gdpr-export-map.yml`, `offboard-book-owner.yml`, `digest-constitution.yml`,
`digest-importers/`. A new state/ file with obligation keys (a lawful basis, a
retention, an erasure order) must be listed there
(gate: `tests/anatomy/test_an_obligation_is_classified.py`).

Generated files: the one list is `generated.yml` (writer, check, header). Here
that is `anatomy-graph.json`, `body-plan.json`, `loop-graph.json`,
`routing-graph.json`, `dpa-register.md`, `devlog-bundle.jsonl`,
`tofu-authentik-services.yml` and `roadmap/index.yml`. Each says
`GENERATED by <writer>` (JSON: `"generated_by"`) and is `merge=regen`
(gate: `tests/anatomy/test_generated_files_hold.py`).

Also here, authored: `night-watch.json` (expectations, merged never regenerated,
ADR 0002), `smoke-catalog.yml`, `roadmap-probes.yml`, `apgar.yml`,
`task-types.yml`, `cortex-lang.gbnf`.

## Moved 2026-10-07 (repo-body-plan I-11)

`router.yml` and `llm-backends.yml` went to `habitat/`. `state/llm-backends.yml`
is a symlink kept for the deployed Wing, which reads it via `NOS_REPO_ROOT`,
until every host has run a `--tags wing` converge; then delete it. The benches
and `fable/` went to `fixtures/`. A code path naming a state/ file that is gone
is refused (gate: `tests/anatomy/test_a_named_state_path_exists.py`).
