nOS — one machine, a whole self-hosted estate

An Ansible playbook converges source into a running estate: ~50 FOSS services, four host organs, an agent runtime, and the loops that let the system improve itself. This page is the bird's-eye view — every figure that moves lives in a reader, not here. live = running today · target = designed, not yet closed.

The one rule

The repo is the source; the estate runs from elsewhere (~/stacks, launchd organs, ~/wing). A converge — ansible-playbook main.yml — is the only thing that moves source into runtime. A git ref answers “what is in the repo”, never “what is running”; the two differ routinely and on purpose.

Configuration — later overrides earlier

default.config.yml      every variable, committed defaults   (~94 install_* toggles)
default.credentials.yml every secret as a template, committed
config.yml              the operator's overrides, gitignored  ← the estate's real flags
credentials.yml         the operator's secrets, gitignored
-e extra-vars           highest precedence, this run only     (profiles live here)

Consequence: a flag read from the default alone is not the flag the estate uses — ask tools/estate-status.py --config <flag> for the resolved value. Two path vocabularies in one run: playbook_dir for this run, nos_main_checkout for anything that must outlive it (Pulse jobs, launchd plists) — so a converge from a worktree never re-points the estate at a feature branch.

What a converge does, in order

preflight   checkout current? main-checkout resolved? forward-auth has an
            Authentik behind it? docker actually answers?
platform    resolve macOS/Linux differences (pkg mgr, service mgr, edge proxy)
host        Homebrew · dotfiles · SSH · runtimes · organs (launchd/systemd)
core-up     infra + observability stacks — always required, always first
            then DB setup, Authentik blueprints/tofu, Infisical, Portainer
configs     Traefik routes (derived from the manifest) · dashboards · scrapes
stack-up    the remaining stacks, parallel by default, STRICT health wait —
            every container must reach healthy; a skip is not a pass
post        service-side SSO wiring · registries · GDPR records
verify      readers check the run's EFFECTS (a success marker is written by
            a reader, never by the code that attempted the work)
smoke       one HTTP probe per service, catalog-gated, honest about UNKNOWN

Declared off ≠ deleted

install_x: false   →  docker stop        reversible · every converge · ungated
uninstall flag on  →  fragment + rm      permanent · deliberate · gated
removal ladder     →  nos --remove=none|data|deep|all   (dry-run without --confirm)

A stopped container stays stopped across reboot (restart: unless-stopped); host daemons get the same split via launchd disable. target for daemons, live for containers.

Gates

~4,600 pytest gates pin shape; --tags verify owns effects; nos-smoke --strict owns end-to-end truth. Every gate is retro-verified against its own broken state — a gate never seen red is not a gate. A release tag refuses to push onto a red trunk.

Axes classify nouns; the two planes (tab 3) classify verbs. One word never carries two meanings — that rule was paid for three times (tier, organ, runner_status).

Edge & public

Traefik is the one edge (80/443), routes derived from the manifest — no per-service proxy config. What the estate shows strangers is a signed projection: the apex ruling names every field VERBATIM / TRANSFORMED / WITHHELD, the build halts on an unruled field, and an agent may add rows but never sign — an amended-after-signing digest is the system working.

A day in the estate

night   Pulse fires the ceremonies: security scans · drift plans · backups ·
        taxonomy upkeep · agent runs — every one a session with a bill
        rc=0 clean · rc=findings — a detector that found something has NOT failed
morning tools/red-status.py — red is a STATE, not a notification stream;
        an unreadable source reports UNKNOWN, never green
always  tools/nos-cc.sh — every tmux pane re-runs a reader; a tailed log
        looks healthy right up until its writer stops

Where it is heading target

The closed loop: the conductor runs the ceremonies on cadence with no human edge; proposals flow from every weakness source; the code graph answers “what breaks if I change this”; and the same organs serve tenant business logic — one estate that maintains itself and does the work, every byte local, every action attributed.
