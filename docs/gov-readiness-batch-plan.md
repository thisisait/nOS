# nOS Gov-Readiness Autonomous Batch — Implementation Plan

## 1. Executive Overview

This is a multi-batch, multi-hour autonomous build punctuated by **operator playbook re-runs**. The organizing principle: **every gov/GDPR control ships default-OFF and provably inert on a normal `ansible-playbook main.yml` run**, and only activates under `-e @profiles/gov-local.yml` plus explicit operator filings. Each batch ends at a **re-run checkpoint** where the operator runs a specific command and validates a specific set of outcomes.

The single highest-value seam in the whole roadmap is **Batch 1**: it wires two controls that already shipped but sit inert (the breach-scan Pulse job and the `wing_audit_chain_enabled` flag) and adds the Wing UI surfaces (audit-chain badge + `/breaches` presenter) so the next gov-local re-run can validate the gov features **end-to-end, visually**, not just via CLI.
