v0.1 proved the spine (identity, catalog, iframe, a real file browser). v0.2 was the
"really get to work" pass — no key feature deferred — and it changed two structural
things before writing a line of feature code.

## The shell moves in-repo

nОS-face's SvelteKit source used to live in a separate repo (`thisisait/nos-face`) that
`roles/pazny.face` git-cloned at a pinned tag. For a big coordinated push that reads badly:
the coherent unit of work is the monorepo. So the shell is now **vendored at
`files/anatomy/face/`**, joining wing/bone/pulse as an in-tree anatomy organ. The role
syncs the tree into its build dir and `docker compose` builds `nos/face` from it (the
keap/puter build-from-source precedent). Reproducibility is now the repo commit itself.
This is the repo's first JS toolchain, too — vitest + eslint + svelte-check.

## A worktree fleet built it

The work fanned out to five agents, each in its own isolated git worktree off a frozen
Wave-0 substrate (the shared TypeScript contracts, the desktop store's `useSnapEngine` /
`usePersistence` extension points, and the server-only API-client layer). Because the seams
were frozen and each group owned a disjoint set of paths, the five branches merged back
into one coherent shell with a single cross-group fix (an image-wallpaper URL). The groups:

- **Snap/tiling WM** — drag a window to the top edge → a dropzone reveals the active
  layout's cells → drop to tile.
- **Control Panel as an icon grid** — each row opens a *window* (not a modal) hosting the
  surface; a generic `DataTableApp` renders it.
- **Wallpapers + per-viewport window caching** — geometry persists keyed by viewport bucket
  `"<w>x<h>"`, 30 s debounced, restored on reload.
- **Config DataTables** — `face.layouts` / `face.wallpapers` / `face.controls` follow the
  SoC → KEAP-DataTable → user-state pattern, with a repo-defaults fallback so the desktop
  stays usable when KEAP is down.
- **nos-native apps** — the pivot away from iframes: a native-app registry, a real VFS
  Files app that *calls* the API, and a two-mode file-picker service.

## The wiring is doctrine, and it bites

Everything is pinned by the repo's enforcement triplet: `docs/doctrine/face.md` →
`tools/face-wiring-report.py --strict` → `tests/anatomy/test_face_*.py`. The hard rules the
gates enforce: identity is edge-token-trusted and `uid` is server-pinned (a spoofed
`X-Authentik-uid` without the edge token is refused — verified live, 403); no `{@html}` in
the shell; tokens never leave `$lib/server`; every config DataTable has a def *and* a
seeder. Bone grew a filename sanitizer (NFC, reserved names, control/BiDi/zero-width,
overlong) applied to every write surface on top of the load-bearing realpath-∈-scope check,
with a 170-test fuzz corpus. The frontend gate (svelte-check + eslint + 76 vitest) and the
python gates run on every CI push and the weekly cron — security is regularly tested, not
one-shot.
