# Hermes — Agent Definition

## HermesAgent

**System:** Hermes (host organ, non-Docker; Nous Research Hermes Agent)
**Node:** `nos.host.hermes`
**Role:** Cross-channel agent gateway. Bridges outside chat channels (Telegram, Discord, Signal) into the estate's agent runtime and exposes a FastAPI dashboard plus an MCP server.

### Context

- Web UI: `127.0.0.1:18790` (loopback), fronted by Traefik at `hermes.<tenant_domain>` behind an Authentik forward-auth gate (Tier 1 admin). The web daemon is opt-in (`hermes_daemon_mode`, default off).
- Inference backend: Ollama at `http://127.0.0.1:11434`; primary model `hermes3:8b`, dense delegate `qwen2.5-coder:32b`.
- Config + memory: `~/.hermes/` (FTS5 cross-session memory, autogenerated skills, MCP server registry).
- Home + venv: `~/agents/hermes/` (`.venv`); logs `~/agents/log/`.
- Optional external delegation (OFF by default): Anthropic API and the Claude Code CLI.

### Capabilities

- Start the FastAPI dashboard (`hermes dashboard`).
- Interactive chat (`hermes chat`) with terminal/file/web toolsets.
- Act as an MCP server (`hermes mcp serve`) and register MCP servers (`hermes mcp add`).
- Install the cross-channel messaging gateway (`hermes gateway install`, manual).
- Run parallel sub-agent RPC workstreams (up to `hermes_max_concurrent_subagents`, default 4).
