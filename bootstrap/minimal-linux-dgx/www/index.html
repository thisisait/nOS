First visit: trust the local certificate authority

  1. Download nos-dgx-rootCA.pem.
  2. Import it as a trusted root: macOS Keychain → System → Always Trust; Windows → certmgr → Trusted Root; Firefox → Settings → Certificates → Import; Linux → sudo cp nos-dgx-rootCA.pem /usr/local/share/ca-certificates/nos-dgx.crt && sudo update-ca-certificates.
  3. Prefer the name __HOST__; by IP (192.168.68.86-style) everything works too when your laptop cannot resolve .local names — the certificate covers both.

Shell access (ssh)

ssh <you>@__HOST__, then /srv/nos-dgx/bin/nos-user-setup once. Everything else is in the knowledge base.
